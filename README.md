# VVP Institute of Engineering & Technology – College Website

A responsive, multi-page college website for **VVP Institute of Engineering & Technology (VVPIET), Solapur, Maharashtra**.

This project provides a web-based platform to explore college information, academic courses, admissions, departments, campus photographs, and contact details.

## 📌 Project Overview

The VVPIET College Website is designed to present important college information through a simple, user-friendly, and responsive interface.

It includes multiple pages to help students and visitors explore the institution and its academic information.

## ✨ Features

- **Home Page:** Introduction and overview of the college.
- **About Us:** Information about the institution.
- **Courses:** Academic courses and program information.
- **Admissions:** Admission-related information.
- **Departments:** Department-related information.
- **Gallery:** Collection of college photographs.
- **Contact Us:** College contact information.
- **Responsive Design:** Layout designed for different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A modern web browser (Google Chrome, Microsoft Edge, Firefox).
- Visual Studio Code (recommended).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kishor96k/VVPIET_MCA_Web.git
   ```

2. Navigate to the project directory:

   ```bash
   cd VVPIET_MCA_Web
   ```

3. Open the project in Visual Studio Code:

   ```bash
   code .
   ```

4. Open `index.html` in your browser, or use the VS Code Live Server extension.
